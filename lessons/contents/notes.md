# Содержание курса — заметки наставника

Лист: `lesson.html` (исходник), `lesson.pdf` (печать, 1 лист А4). Кладётся первым в
конверт, остаётся у неё вместе с уроками.
Собрать заново: `uv run scripts/build_lessons.py contents`.

- Список уроков 0–7 — по `course/skill_map.md`. Добавился урок — добавить строку.
- Клетка «Получилось» — галочку ставит она сама, когда выполнен «Получилось, если…»
  урока (`course_rules.md` п. 3.3: следующий урок — только после этого).
- Подписи под названиями — чем делается действие, словами уроков (боковая кнопка,
  зелёная трубка, кнопка громкости, «Домой»). Новых слов нет.
