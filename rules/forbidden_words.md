# Запрещённые слова

Единый список для всех уроков. На него ссылаются `lesson_rules.md` п. 4.4 и
`course_rules.md` п. 4.4. Новое слово — сюда, а не в правила.

## 1. Слова, которые всегда заменяем

| Нельзя | Пишем | Почему |
|---|---|---|
| глядя (в лист, на экран) | смотреть: «смотрели в этот лист», «посмотрите на экран» | решение пользователя |
| кнопка питания, кнопка включения | боковая кнопка | одна вещь — одно имя (п. 4.5), введено в уроке 0 |
| смахнуть, провести, свайп | потянуть | один жест — одно имя, введено в уроке 1 |
| тапнуть, коснуться, кликнуть | нажать | «нажать» она знает по кнопочному телефону и пульту |
| принять вызов | ответить | её слово |
| отклонить, сбросить, завершить вызов | красная трубка / закончить разговор | введено в уроке 1 |
| вызов | звонок | её слово |
| дисплей | экран | одна вещь — одно имя |
| внук, внучек | Женя | решение пользователя |
| рабочий стол, домашний экран | главный экран | решение пользователя 28.10.2026; одна вещь — одно имя; в руководстве — Home screen |
| контакты (как название вещи) | записная книжка; «Контакты» — только как надпись на телефоне | её слово |
| значок, иконка | описать по виду: «зелёная трубка», «красный кружок» | значки пожилые понимают плохо (`lesson_rules.md` п. 3.5) |

| программа | — (синоним «приложения» — не вводим) |
| интерфейс | — |
| уведомление | — |
| настройки | — |
| разблокировать | — (урок 3 говорит «разбудить телефон», «дойти до главного экрана») |

## Проверка урока

```bash
grep -rniE 'внук|глядя|питани|смахн|провед|свайп|тапн|коснит|кликн|принять|отклон|сбрось|вызов|дисплей|значок|иконк|программ|интерфейс|уведомлен|настройк|разблокир|рабочий стол|домашн' lessons/*/lesson.html
```

Пусто — урок чистый. Вхождение в комментарии HTML не в счёт: бабушка его не видит.
