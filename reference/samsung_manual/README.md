# Руководство Samsung Galaxy A37 5G (SM-A376)

`a37_manual.pdf` — «Samsung Galaxy A37 5G A376 User Guide», автор Samsung, 144 стр.,
создан 04.03.2026. Издание США (англ.). Скачано 28.10.2026 с
https://files.phonecompass.com/2026/04/samsung-galaxy-a37-manual.pdf (сторонний хостинг,
метаданные — Samsung). `a37_quickstart.pdf` — краткое руководство оттуда же.

PDF в git не кладём (9 МБ) — только эта выжимка.

## Факты для уроков (проверено по страницам)

| Что | Как в руководстве | Стр. |
|---|---|---|
| Ответить на звонок | «On the incoming call screen, drag **Answer** to the right» — зелёную трубку **тянуть вправо** | 71 |
| Отклонить звонок | «drag **Decline** to the left» — красную трубку тянуть влево | 71 |
| Положить трубку | «Tap **End call**» — красная кнопка, **нажать** | 71 |
| Звонок поверх другой программы | приходит всплывающим окном; вид задаётся: Phone → Settings → Call display while using apps → Full screen / Small pop-up / Mini pop-up | 71–72 |
| Ответ кнопкой громкости | Settings → Accessibility → Interaction and dexterity → Answering and ending calls → **Press Volume up to answer calls** | 137 |
| Сброс боковой кнопкой | там же → **Press Side button to end calls** | 137 |
| Жест ответа | там же → Gesture to answer calls (выбор жеста) | 137 |
| Кнопки внизу экрана | Settings → Display → Navigation bar → **Buttons**: «Недавние» `III` слева, «Домой» `○` в центре, «Назад» `<` справа | 17 |
| Включить / выключить | включить — держать боковую кнопку; выключить — держать боковую + громкость вниз, нажать Power off | 9 |
| Корпус | рисунок телефона: кнопки справа, разъём и лоток SIM снизу, камера-точка сверху по центру | 6 |

## Оговорки

- Издание США. **гипотеза:** в российской/европейской прошивке названия пунктов на русском,
  набор программ (например, для СМС) может отличаться.
- Подпись в руководстве: «illustrations are for reference only» — рисунки ориентировочные.
- Снимка экрана входящего звонка в руководстве нет — только значки кнопок.
